# Ива — персональный ассистент

Исходники локальной версии из `main_agent`, скопированной с рабочего сервера
28 октября 2026 года. Код импортируется из файлов владельца, с сохранением
структуры каталогов.

## Состав

- `iva/local_finance`, `iva/plugin` — финансовое ядро и интеграции.
- `iva/iva_integration` — Telegram, маршрутизация агентов, голос, документы,
  тендеры, исследования спроса, браузерные инструменты и личные навыки.
- `iva/data/iva-pilot/app` — исходники самого нативного движка Ивы, его тесты,
  инструкции, навыки, пакетные модули, сервисы и lock-файлы зависимостей.
- `iva/deploy`, `iva/scripts`, `iva/config`, `iva/docs`, `iva/tests` — установка,
  обслуживание, примеры настройки, документация и тесты интеграций.
- `lead-flow` — CRM, исследование OCR/HR-лидов, независимая проверка писем
  и детерминированная отправка через `mailer.dispatcher`.
- `server-config/usr`, `server-config/etc/systemd` — служебные скрипты и systemd.

Обзор эксплуатации: [инструкции Ивы](iva/AGENTS.md),
[развёртывание](iva/docs/VPS-DEPLOYMENT.ru.md),
[HR-обработчик](lead-flow/hr_campaign.py),
[отправка писем](lead-flow/mailer/DISPATCHER.ru.md).

## Настройка

Рабочий сервер использует Linux, Python и Node.js 24+. Нативные JS-зависимости
зафиксированы в `iva/data/iva-pilot/app/package-lock.json`; установка — `npm ci`
из этого каталога. Python-зависимости перечислены в requirements-файлах
соответствующих компонентов. Перед запуском нужно отдельно настроить секреты,
авторизацию CLI, приватные файлы конфигурации и начальные базы данных согласно
документации. Добавление репозитория само по себе ничего не запускает.

## Границы публичного репозитория

Здесь опубликован код. Полная локальная копия, архивы и приватное состояние
сохранены на компьютере владельца и описаны в LOCAL-SERVER-COPY.ru.md.
В Git не включаются `.env`, ключи, пароли, OAuth/браузерные сессии, переписка,
документы, финансовые базы, память, рабочие очереди, резервные копии и
установленные среды `node_modules`/`.venv`. Разовые скрипты с личными кредитами
и платежами также остаются локально. Манифест импорта фиксирует перечень
исходников и контрольные суммы: [SOURCE-MANIFEST.json](SOURCE-MANIFEST.json).

Рабочие данные не являются демонстрационными: локальные копии нельзя использовать
как второй активный финансовый реестр или запускать рядом с действующим ботом.
