# Проверка срока и состояния сессии Ивы

28 октября 2026: вопрос о состоянии тендерного поиска попал в сессию,
которая уже завершилась по суточному сроку жизни. Проверка last_used
ошибочно считала её действующей. Сам фоновый поиск продолжал работать.

durable-turn.mjs теперь сохраняет время создания, не обновляя его при
последующих сообщениях. telegram-turn.mjs передаёт каталог локальных
workflow-записей; перед присоединением проверяются runId, состояние
pending/running и возраст менее 23 часов от создания. Завершённая,
просроченная, отсутствующая или повреждённая запись требует новой сессии.
Счётчик сообщений сбрасывается при создании новой сессии.

Обновление применяется к следующему запуску telegram-turn.mjs без рестарта
служб. Активные research jobs, исходные сообщения и финансовый реестр
не изменяются. Повторная доставка уже выполненного или неопределённого
поручения по-прежнему не вызывает его повторное выполнение.
