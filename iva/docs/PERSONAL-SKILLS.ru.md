# Личные навыки Ивы

Владелец может попросить Иву создать способ работы обычным текстом или голосом.
Ива сама пишет инструкцию через `personal_skills`, сохраняет её и продолжает
диалог: недостающие личные предпочтения можно выяснить после создания навыка.
Навыки используют уже подключённые инструменты; новые программы и внешние
подключения этим механизмом не устанавливаются.

`create-personal-skill` объясняет авторство инструкций. Готовый
`personal-movie-discovery` начинает с просмотра памяти и опроса о понравившихся
фильмах, ищет через `web_browser`, различает просмотренное и предложенное,
запоминает оценки и причины, проверяет алиасы и годы, исключает просмотренное.
Начальное состояние не содержит выдуманных вкусов или просмотров.

## Хранилище

Каноническая база: `data/personal-skills/state.sqlite3`. В ней инструкции,
версии, записи памяти с версиями, цитатами и источниками, а также журнал запросов
для защиты от повторов. `expected_revision` обязателен для записи: 0 при создании,
прочитанная версия при обновлении. Поля JSON памяти дополняют существующие;
непереданные поля не удаляются. Значение watched нельзя выводить из рекомендации.
Исправленная оценка или просмотр дополняют ту же запись фильма.

Инструкции публикуются атомарно в
`data/iva-pilot/app/data/custom/agent/skills/personal-*/SKILL.md`.
Штатный динамический загрузчик Eve подхватывает их на следующем ходе, без сборки
и рестарта. После save в текущем ходе модель может продолжить по возвращённой
инструкции. SQLite — источник истины; сбой публикации явно возвращает saved=true,
published=false, ok=false. Повтор исходного запроса или list восстанавливает
проекцию, не создавая повторной версии. Устаревший повтор не отменяет новые правки.

## Инструмент

- `list/read` — найти навык и прочитать полную инструкцию/версию.
- `save` — создать/обновить инструкцию, описание до 120 символов, текст до 20000.
- `archive` — убрать из каталога, оставляя версии и память; save восстанавливает.
- `recall` — записи навыка по key/query, limit 1–100, offset, next_offset.
- `remember` — создать/уточнить запись с JSON object, ключом и версией.

HTTP `/personal-skills` использует существующий внутренний токен gateway.
Изменения требуют текущего обрабатываемого прямого Telegram-конверта владельца
и точной цитаты его текста/транскрипта. Пересланное, документы и прежние сообщения
не дают права менять навыки. Намерение понимает модель: словаря ключевых слов,
чувствительного к опечаткам, здесь нет. Слоты имеют префикс personal-; выход из
каталога, симлинки, подмена чужого навыка и запись исполняемого кода не допускаются.

## Развёртывание и проверки

`deploy/personal_skills_integration.py` добавляет небольшие блоки в свежие
gateway/prepare_pilot/iva_telegram/backup. Старые копии общих файлов не переносятся
поверх правок соседних сессий. `deploy/install_personal_skills.py` отказывается
работать при активном пользовательском ходе или известной сборке, проверяет
хеши перед заменой, сохраняет откатные исходники и сборку. Тендерный код и его
служба не перезапускаются. Основные сервисы возвращаются и при ошибке.

`tests/test_personal_skills.py` проверяет сохранение после открытия, версии,
память, защиту от повторов, конфликт версий, архив, восстановление после сбоя,
пагинацию, границы путей и HTTP-авторизацию с опечаткой.
`deploy/verify_personal_skills.py` проверяет реальную Luna с настоящей схемой
инструмента на временном хранилище: создание инструкции, память о просмотре,
новый разговор и подбор с чтением памяти. Его браузерная выдача — явно
помеченная тестовая фикстура для проверки исключения просмотренного, не проверка
живого интернет-поиска. Рабочий поиск остаётся существующим `web_browser`.

Ежедневная резервная копия включает согласованный SQLite-снимок личных навыков
и каталог их инструкций. При восстановлении базы вызов list восстанавливает
недостающие файлы. Отчёты и откатные файлы развёртывания:
`data/personal-skills-release-20261021/`.
