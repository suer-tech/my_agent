# Интернет и маркетплейсы Ивы

В Telegram-Иву подключён нативный инструмент `web_browser`, использующий Python Playwright и отдельный Chromium. Он работает через существующий loopback-шлюз, а не через инструменты разработчика или MCP конфигурацию Codex CLI. Модель остаётся GPT-6 Luna low. Платный поисковый API для этого подключения не нужен.

Действия: `open(url)`, `search(query, marketplace)`, `read`, `scroll`, `close`. `marketplace` — `web` (Bing), `ozon`, `wildberries`, `yandex_market`. Ссылки из результата открываются через `open`. Результат содержит видимый текст, ссылки, структурированные Product/Offer при наличии, фактический URL и время проверки. У веб-поиска отдельно проверяется наличие карточек выдачи; загрузка пустой страницы не считается найденными результатами.

Это анонимный читатель: профиль владельца, cookies его обычного браузера и аккаунты не подключаются. Инструмент не предоставляет произвольный JavaScript, загрузку файлов, ввод форм, корзину, оформление заказа или оплату. GET/HEAD запросы разрешены только на публичные HTTP(S) адреса; локальные адреса, WebSocket и POST блокируются. Из-за этого некоторые интерактивные сайты могут работать частично. Браузер имеет одну последовательную очередь и общий контекст для единственного владельца бота. `close` очищает контекст, перезапуск шлюза также сбрасывает его.

Загрузка навыков через `load_skill` включена. Навык `marketplace-shopping` объясняет проверку вариантов, цены за единицу, обычной и условной цены, доставки, продавца, источника и связи с семейным прогнозом. Поиск не создаёт фактических расходов. Создавать новые навыки сама Ива пока не может: чтение/загрузка включены, запись пользовательских навыков и автоматический цикл обучения не подключены. Нативный механизм Ивы умеет подхватывать сохранённые пользовательские навыки, но сам по себе не создаёт их из повторений.

## Что проверено 19 октября 2026

- Реальная Ива через Codex CLI загрузила навык, прочитала страницу Playwright, вернула её заголовок и команду установки со ссылкой. Финансовые операции не изменились, integrity_check=ok.
- На контролируемой HTML-странице реальный Chromium извлёк SKU, цену, валюту, ссылку и видимый текст товара.
- Всего прошли 198 Python-тестов и 4 Node-теста, включая прежнюю защиту от повторных финансовых записей.
- При проверке Luna один раз ошибочно заявила об отсутствии браузера при его наличии в manifest. Добавлены явный текущий контракт браузера и ограниченная проверка read при таком отказе. Повторный реальный диалог выполнил поиск Ozon и верно сообщил о HTTP 403 и неподтверждённой цене.
- Реальные запросы к Ozon, Wildberries и Яндекс Маркету с текущего подключения получили антибот-страницы/403/498. Подключение браузера не означает подтверждённый доступ к их каталогам. Google и DuckDuckGo также ограничили проверочные запросы, Bing загрузил страницу без подтверждённых карточек выдачи. Цены на этих сайтах в данной проверке получить не удалось. Обход защит не реализован. Для надёжного поиска ссылок отдельно можно подключить поисковый API; это не гарантирует доступ к закрытой карточке товара.

Отчёт реального диалога: `data/iva-telegram/tests/playwright-1792417279562927900/verification.json`. Источники модуля: `iva_integration/web_browser.py`, `iva_integration/web_browser.ts`, `iva_integration/skills/marketplace-shopping.md`.

При переносе: `python -m pip install -r requirements-browser.txt`, затем `python -m playwright install chromium`; скопировать нативный инструмент и навык в приложение Ивы, пересобрать и штатно перезапустить. `prepare_pilot.py` сохраняет и копирует эти файлы, но запускать его только ради браузера не требуется: он также меняет прочую конфигурацию пилота.

## Календарь

Финансовый календарь и платёжные напоминания за день с 09:00 Екатеринбурга работают. Позднее 19 октября подключены общий локальный календарь, обычные напоминания и ежегодные дни рождения через personal_calendar и отдельный Telegram-диспетчер; см. [личный календарь](PERSONAL-CALENDAR.ru.md). Сохранённая только в памяти дата сама по себе не создаёт уведомление — событие нужно записать инструментом календаря. Старый нативный remind не используется.
