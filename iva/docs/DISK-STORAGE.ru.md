# Диск сервера Ивы

`disk_storage` подключён к VPS; `/disk` в Telegram показывает место без ожидания модели.
Обычные просьбы «сколько свободно», «что занимает место», «найди мусор» вызывают
status/analyze. Анализ показывает объёмы каталогов, причины и потенциальный объём
очистки. Размер каталога сам по себе не означает ненужность данных.

Ясная команда «очисти кэш npm», «удали найденный безопасный мусор» разрешает очистку
выбранных доступных кандидатов без второго разрешения/кодов. Для устаревших копий
нужна команда именно о копиях. Свежий анализ можно выполнить в том же ходе.
Список действует 30 минут; изменившиеся или занятые данные пропускаются.

Автоматическая очистка ограничена фиксированной политикой: кэши pip/npm root и iva,
заголовки node-gyp, скачанные пакеты apt, стандартные архивы server-backups старше
14 дней с сохранением минимум двух последних. Следующая установка может скачать
пакеты снова. Произвольных shell-команд и путей в интерфейсе нет.
Базы, память, документы, исходники, копии отката, браузеры Playwright, голосовая
модель, swap, активные журналы и текущие исследования не являются кандидатами.
Нестандартные старые окружения/архивы можно увидеть в размерах, но их важность
требует отдельного разбора; инструмент не объявляет их мусором автоматически.

Перед удалением gateway проверяет сохранённый Telegram-конверт, текущий processing
source, владельца, точную цитату и область команды. Вложения/пересылки/цитаты и
вопросы о месте не дают права удаления. Привилегированный helper заново проверяет
политику, отпечаток файлов и процессы, отклоняет symlink/hardlink/mount/special files.
Каталоги открываются через nofollow dirfd; удаление выполняется через защищённый
от symlink-подмен rmtree. При изменении после перемещения удаление отменяется.
Журнал data/disk-storage/audit.sqlite3 отделён от финансов и включён в бэкап.
Повтор source возвращает прежний результат; неясный исход после сбоя не повторяется.
Фактический прирост свободного места может отличаться от размера удалённых данных
из-за параллельной работы. Нет автоматического ежедневного удаления или мониторинга.

Helper устанавливается root-owned в /usr/local/sbin/iva-disk-storage (Python -I).
Sudoers разрешает iva только этот исполняемый файл без аргументов; JSON stdin
проверяется отдельно. Код из iva-owned checkout root-процесс не импортирует.
