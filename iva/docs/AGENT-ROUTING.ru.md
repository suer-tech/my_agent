# Маршрутизация Ивы

Весь обычный текст и распознанная речь сначала поступают главной Иве: `gpt-6-luna`, рассуждение `low`. Транспортные команды подтверждения, восстановления и кнопки напоминаний обрабатываются отдельно.

Финансовая часть целого сообщения передаётся инструменту `finance_agent`. Это отдельный цикл модели `gpt-6.1-sol` с рассуждением `medium`: он получает исходное авторизованное сообщение, финансовую память, правила навыка и методы финансового ядра. Главная Ива не вызывает прежние прямые финансовые инструменты. Если сообщение смешанное, календарь и остальные задачи остаются у главной Ивы.

Субагент понимает задачу и выбирает инструменты; ядро проверяет счета, суммы, даты, ссылки на план, выполняет расчёты и транзакции SQLite. Ясные фактические доходы и расходы сохраняются сразу. Несколько операций одной просьбы сохраняются атомарно. Ясные команды сохранить месячную статью бюджета, ожидаемый доход, остаток или метод оценки выполняются сразу через finance_save_plan. Неизвестные существенные поля уточняются; формальное повторное подтверждение не требуется. План не создаёт фактическую проводку, а частичная оплата связывается с ним без двойного учёта. Нельзя считать оплату взноса полным закрытием кредита или превращать перевод своих средств в доход.

Оригиналы вложений и извлечение сохраняются до модельной обработки; затем документ с подписью поступает Иве, а финансовый документ — субагенту. Оплаченный чек проверяется по текущему сохранённому вложению, его суммы модель произвольно не подставляет.

У каждой делегации стабильный источник. Завершённый запрос возвращает сохранённый результат; незавершённый требует сверки и не запускает запись повторно. Похожие операции из нового сообщения требуют уточнения. Гарантировать отсутствие любых ошибок модели нельзя; защита ограничивает последствия и не сообщает об успехе без результата инструмента.

Профили: `data/iva-agents.json`. Профиль тендеров также Sol 6.1 medium, но выключен: существующий механизм поиска владельца ещё не подключён. Настройка профиля сама по себе не означает работающий поиск.

Модели запускаются локальным Codex CLI с существующей авторизацией. Голос, память и календарь остаются общими для Ивы. Данные финансов находятся в `data/local-finance.sqlite3`.
