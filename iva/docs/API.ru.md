# Контракт финансового модуля

Один MCP tool `finance`, аргументы `{ "action": "...", "payload": {...} }`. Список действий с параметрами есть в `tools/list` и `server.py`. Также доступен CLI: `python plugin/family-finance/server.py --db data/finance.sqlite3 --call ACTION --payload JSON`. В PowerShell сложные JSON удобнее передавать через Python-скрипт или MCP, чтобы избежать shell-экранирования.

Python API (путь `plugin/family-finance` должен быть в `sys.path`):

```python
from finance.core import Ledger
l = Ledger('data/finance.sqlite3')
card = l.account('Основная карта', '30000.00', '2026-10-18')['id']
l.configure(reserve='10000.00', daily='500.00', daily_account=card)
l.schedule('Зарплата', 'income', '90000.00', card,
           monthday=25, start='2026-10-19', lead_days=1)
l.schedule('Аренда', 'expense', '20000.00', card,
           monthday=22, start='2026-10-19', lead_days=5)
d = l.stage({'kind':'expense', 'amount':'1499.90', 'date':'2026-10-19',
             'account':card, 'note':'Продукты', 'ambiguities':[]},
            source='telegram:123:456:0')
# Сначала показать кандидата пользователю и получить ответ:
l.confirm(d['id'], confirmed=True)
report = l.forecast('2026-10-19', '2026-11-30',
                    purchase={'amount':'10000.00', 'date':'2026-10-21', 'account':card})
```

`as_of` и остатки означают конец дня. Операции должны быть позже начального остатка участвующих счетов. При добавлении нового счёта прогноз не строится до его начальной даты. Факты после `as_of` учитываются в будущем; факты до него уже входят в остатки. Это не счётчик повседневных расходов за сегодня: дневной бюджет применяется со следующего дня. Ожидаемые расходы с начала учёта до `as_of`, ещё не связанные с фактом, переносятся в прогноз как неоплаченные; нужно сверять и закрывать их.

Поля результата прогноза: `days`, `minimum`, `minimum_accounts`, `first_gap`, `reserve`, `daily_budget`, `budget_configured`, `affordable`, `overdue_unsettled`. Все денежные числа — **целые копейки**. `first_gap` учитывает и промежуточный расход до зарплаты в один день; остаток в конце дня может быть положительным. `affordable` условен относительно достоверности всех планов, а не гарантия дохода.

`calendar(start,end)` возвращает неоплаченные ожидания с `occurrence`. Это внутренний календарь, синхронизации Google/Apple Calendar сейчас нет. Ссылку `occurrence` переносить в факт дохода/расхода — иначе ожидание останется и прогноз посчитает его отдельно. Сумма факта может отличаться от плановой. Отмена правила `cancel_schedule(id,from_date)` прекращает все будущие его события. Изменение регулярной суммы: остановить старое правило и создать новое со следующей даты; история остаётся.

Чек: `stage` допускает неполного кандидата и список `ambiguities`; без уточнения обязательных полей/сомнений `confirm` откажется. `source` — идентичность Telegram-сообщения и номера операции. Тот же source возвращает тот же черновик/факт; другая source с совпавшими видом/суммой/датой/счетами даёт `possible_duplicate`. После отдельного ответа пользователя разрешается `allow_similar=True`. Защиты по ФН/ФД/ФП и изображению пока нет: смысловой дубль с изменённой датой/суммой может потребовать ручной сверки. Для отменённого факта тот же source не оживляет запись — нужен новый source исправления.

`void(operation_id,reason)` сохраняет запись и аудит; новый факт добавляется отдельно. Между отменой и новым подтверждением реестр содержит отмену без замены — эту двухшаговую правку нужно завершить. Модуль не выполняет произвольный SQL или shell из MCP. Чтение `snapshot` содержит приватные данные и не должно передаваться внешним агентам без необходимости.

Кредиты: `loan(...)` добавляет условия; `loan_scenario(id)` — базовый график; варианты `extra='1000.00'`, `lump_sum='10000.00'`, `mode='term'|'payment'`. Разовый взнос применяется перед первым начислением. `fees` — фиксированная комиссия, включённая в месячный платёж. Ежемесячное досрочное погашение добавляется сверх платежа. Результат включает `months`, `interest`, `fees`, `overpayment`, `total_paid`, `schedule`; реестр денег не изменяется. Условия/договоры не загружаются автоматически. Для общего бюджета шести кредитов не суммируйте одновременно независимые сценарии с одним и тем же свободным рублём.
