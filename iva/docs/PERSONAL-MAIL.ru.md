# Яндекс Почта владельца

`personal_mail` подключает `suer888@yandex.ru` по IMAP/TLS (`imap.yandex.ru:993`).
Доступ действует после ввода и реальной проверки отдельного пароля приложения.
До этого `status` честно сообщает об отсутствии подключения. Обычный пароль
аккаунта, SMTP и отправка писем не используются.

Действия: `status`, `folders`, `list`, `search`, `read`. Все папки открываются
readonly, содержимое читается через BODY.PEEK: флаги прочтения не меняются.
`search` проверяет тему, отправителя, получателя и Message-ID последних
`scan_limit` писем выбранной папки (300 по умолчанию, максимум 1000). Это не
полный поиск по содержимому/всей истории. Ответ содержит фактическое покрытие
и `older_unscanned`; другие папки проверяются отдельно. `read` использует UID
и возвращает UIDVALIDITY; переданный устаревший UIDVALIDITY отклоняется.
Текст ограничен, письма больше 12 МБ целиком не загружаются. Список вложений
виден, скачивание вложений этим инструментом не реализовано.

HTML преобразуется в текст без скриптов и внешних изображений. Письма и ссылки
не считаются поручениями владельца. Фоновое чтение, уведомления, отправка,
удаление и смена настроек ящика не подключены. Пароль не входит в схему
инструмента; модель получает только результат чтения.

Приватная настройка: `.task-tools/yandex_mail_private_setup.py` на компьютере
владельца открывает одноразовую форму только на 127.0.0.1. Пароль через
проверенный SSH передаётся в `configure`, проверяется IMAP и атомарно
записывается в `/opt/iva/data/mail/yandex.json` с правами 0600, каталог 0700.
Ни секрет, ни содержимое писем не пишутся в журнал/память. Форма закрывается
после успеха или через 30 минут. Самостоятельно отозвать доступ можно,
отменив пароль приложения «Ива» в Яндекс ID. Секрет не включён в общий
архив проекта или ежедневную копию памяти; после потери сервера потребуется
повторное подключение.

Установка: `deploy/install_mail.py` блокирует конкурентное развёртывание,
проверяет отсутствие активного диалога, правит свежие общие файлы точными
вставками, сохраняет откатную сборку, проверяет целевые тесты и собирает Иву.
При ошибке возвращает исходники/сборку и службы. Финансовые операции до/после
сверяются по хешу; тендерный обработчик не перезапускается.

Проверки: `python -m unittest discover -s tests -p test_personal_mail.py -v`.
Тестовый IMAP проверяет отсутствие мутаций/Seen, покрытие поиска, UIDVALIDITY,
запрет секретов в аргументах, HTML и атомарную запись приватных учётных данных.

## Реальная проверка 21.10.2026

Пароль приложения введён владельцем в локальной форме. Настоящий IMAP-вход
успешен; через авторизованный gateway получены заголовки последних 20 писем
и прочитаны два уведомления Росэлторга (UID3083/3084, UIDVALIDITY1428422225):
заявка №3701523 по процедуре №0161600001326000063 подана, обеспечение
16 000 ₽ заблокировано по сообщению банка площадке. Непрочитанные флаги
сохранены. Номер и тексты уведомлений добавлены в память через нативные
write_card/commitVaultWrite/writeCore с проверкой чтением. Переданы 17
оригиналов и 17 читаемых источников закупки. Реальная Luna вызвала personal_mail
status и до настройки честно сообщила об отсутствии подключения.
