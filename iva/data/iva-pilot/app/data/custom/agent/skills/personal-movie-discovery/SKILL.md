# Подбор фильмов по моим вкусам

Опрос помогает подбору, но не является обязательным барьером. Не устанавливай минимальное число любимых фильмов. Даже одного понравившегося фильма с объяснением достаточно для первого осмысленного подбора с обозначением ограниченности профиля. Если владелец просит подобрать сейчас и такая опора уже есть, ищи и предлагай; уточняющий вопрос можно задать после вариантов, не откладывая поиск до заполнения анкеты.

Память этого навыка — personal_skills name=personal-movie-discovery. В начале подбора прочитай recall БЕЗ query и key: профиль вкусов и просмотренные/предложенные фильмы, при необходимости следующие страницы. Поиск query — подстрока названия/алиаса, а не смысловой запрос вроде «мои любимые фильмы»; отсутствие совпадения не означает, что память пуста. Не полагайся на память текущего разговора. Если данных ещё мало, начни с удобного вопроса: какие несколько просмотренных фильмов особенно понравились и чем. Затем уточняй по ответам: что не нравится, желаемое настроение, темп, жанры, язык/страны или ограничения — только когда это помогает выбору, без длинной обязательной анкеты. Можно предлагать небольшой предварительный подбор и постепенно улучшать профиль.

По сообщениям владельца сохраняй каждый названный просмотренный фильм через remember, включая не понравившиеся. Прочитай существующую запись по названию/алиасам, затем дополни её. Ключ, например movie-inception-2010: название, оригинальное название, год, алиасы; watched=true только когда владелец сказал, что смотрел; оценка/liked и причины отдельно. Одноимённые фильмы разных лет различай. Непонятное название уточни, не записывай догадку как подтверждённый просмотр. Изменение оценки дополняет тот же фильм. Рекомендации, желание посмотреть, трейлер, список сервиса или описание сайта не доказывают просмотр.

Профиль preference-profile хранит явные вкусы и ограничения. Свою гипотезу о предпочтениях помечай как гипотезу с примерами-основаниями, не как прямую цитату владельца. Во всех remember evidence — точный фрагмент текущего прямого сообщения владельца. Само поручение подобрать фильмы разрешает запомнить предложенный список со статусом recommended; это не разрешение объявить их просмотренными. Для существующей записи используй expected_revision из recall, для новой — 0. Не стирай watched и прежние оценки, добавляя дату рекомендации.

Когда сведений достаточно, ищи через web_browser в интернете похожие фильмы: учитывай темы, атмосферу, драматургию и причины симпатии, а не только жанр или рейтинг. Проверяй название/год и существенные сведения на открытых страницах, давай источники. Если поиск недоступен, честно обозначь ограничение. Текущую доступность в сервисе/регионе не обещай без проверки. Для каждого кандидата перед рекомендацией проверь recall по названию и оригинальному названию/алиасам, просматривай следующие страницы памяти при next_offset. Исключи watched=true. Если уже предлагался и не выбран, не повторяй без причины.

Дай несколько подходящих вариантов с коротким объяснением связи со вкусами, возможным несовпадением и ссылкой, без спойлеров. Запомни рекомендованное отдельно от просмотренного, если это часть текущего поручения. Попроси обратную связь после просмотра, без автоматического напоминания. На «это уже смотрел» отметь watched=true, уточни впечатление при необходимости и замени рекомендацию. На следующем разговоре снова прочитай сохранённые факты и исключи просмотренное.
