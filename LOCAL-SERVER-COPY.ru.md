# Локальная копия рабочего проекта Ивы

Источник: сервер `5.63.152.247`. Копирование основного проекта завершено
28.10.2026 12:33:18 по Екатеринбургу. Серверные службы во время копирования работали.

- `iva/` — полный рабочий каталог `/opt/iva`: код, документация, данные,
  память, документы, настройки, установленные зависимости и история выпусков.
- `lead-flow/` — полный `/opt/lead-flow`, включая HR-поиск и `mailer.dispatcher`.
- `server-config/` — связанные настройки из `/etc`, служебные скрипты
  `/usr/local`, файлы CLI-login/config и постоянное состояние из `/var/lib`.
- `.local-before-server-sync-20261028/` — прежние локальные папки до обновления.
- `.server-backups/iva-full-project-20261028.tar.gz` — полный Linux-архив проекта.
- `.server-backups/iva-server-state-20261028.tar.gz` — дополнительное служебное состояние.

Архивы проверены по SHA-256. Основной импорт: 140,841 файлов;
SQLite-баз с проверенными онлайн-снимками: 123.
Контрольные суммы и результаты проверки находятся в `.server-backups/`.

Это снимок, автоматической синхронизации с сервером нет. Финансовый реестр
и работающий Telegram-бот остаются на сервере. Локальные службы не запускались.
SQLite-базы копировались через backup API, остальные файлы — отдельно из
работающей системы; время снимка каждой базы сохранено в манифесте.

Linux-символические ссылки сохранены в исходном архиве; список —
`.server-backups/project-LINUX-LINKS.json`. При распаковке в Windows неподдерживаемые
имена и коллизии регистра отображены в `.server-backups/project-WINDOWS-PATHS.json`.
Архив сохраняет исходные имена и Linux-метаданные. Linux-зависимости из снимка
предназначены для восстановления Linux-среды; для запуска под Windows нужна
отдельная настройка окружения.

Копия содержит приватные настройки и пользовательские данные. Соответствующие
каталоги исключены из Git через корневой `.gitignore`.
